# 尊者直播监控 — 需求与目标（冻结版）

> 本文件是项目的**唯一需求依据**，冻结后任何开发、测试、验收都以本文档为准。
> 变更需求必须先改本文件、再改代码。最后更新：2026-08-19

## 一、项目定位

个人自用的多平台直播监控录制 + 博主发布视频监控下载 + 复盘流水线（转写/提炼/切片）工具。
macOS 优先，兼容 Windows。内容仅本地保存，供个人学习复盘，不传播。

## 二、功能需求与验收标准

### A. 直播监控与自动录制

| # | 需求 | 验收标准 |
|---|---|---|
| A1 | 多平台开播检测（当前实际使用 B站，框架支持 40+ 平台） | 配置直播间后，daemon 每轮真实检测（日志 `checked > 0`），开播可被检测到 |
| A2 | 自动录制直播流（ffmpeg） | 开播后自动拉起 ffmpeg 录制，产出 ts/mp4 文件到 downloads |
| A3 | 录制完成自动触发复盘流水线 | 录完自动入队转写→提炼→切片 |
| A4 | 开播/关播通知（邮箱/微信，每主播可覆盖） | 配置真实凭据后，开播发通知、关播按开关发通知 |

### B. 发布视频监控与下载（核心）

| # | 需求 | 验收标准 |
|---|---|---|
| B1 | 博主已发布视频浏览 | `blogger-videos` 返回标题/封面/日期/时长/已下载标记，桌面端可展示 |
| B2 | 选择下载（单选/批量/全部） | 可对单个/多个/全部视频发起下载 |
| B3 | **收集博主全部历史视频** | 提供"下载全部历史视频"能力，能把基线中未下载的视频全部入队下载（当前缺失，必须补齐） |
| B4 | 新视频自动检测+通知+按需下载 | daemon 每轮检查监控源，发现新视频：邮件通知 + 按配置自动下载 |
| B5 | 下载完成自动复盘 | 下载成功后自动入队复盘流水线 |
| B6 | 多平台视频源（B站/抖音/小红书等） | 每个配置的源都能拉到视频列表；源故障要可见、可恢复 |

### C. 复盘流水线

| # | 需求 | 验收标准 |
|---|---|---|
| C1 | 转写（faster-whisper，带时间戳） | 输出 `*.转写.txt` + `*.转写.json` |
| C2 | 知识提炼（OpenAI 兼容 LLM） | 输出 `*.知识点.json` + `*.复盘笔记.md` |
| C3 | 精华切片（ffmpeg 无损） | 输出 `精华切片/` 视频片段 |
| C4 | 复盘笔记邮件推送 | 配置真实邮箱后能发出 |
| C5 | 训练数据导出 JSONL | `export-training-data` 输出一行一条记录，含主播/日期/时间戳 |
| C6 | 转写/提炼/切片三开关（全局+每主播覆盖） | 各开关独立生效 |

### D. 通知系统

| # | 需求 | 验收标准 |
|---|---|---|
| D1 | 邮箱通知（SMTP，QQ 邮箱默认） | 配真实授权码后 `test-email` 能真正发出邮件 |
| D2 | 微信/Server酱（可选） | 配接口后能发出（缺凭据标记跳过） |
| D3 | 每主播可覆盖通知渠道 | 监控偏好里的 notify 字段生效 |
| D4 | 本地兜底（桌面端通知） | 桌面端本地通知可用 |

### E. 界面与接口

| # | 需求 | 验收标准 |
|---|---|---|
| E1 | Electron 桌面端 | 表格管理直播/视频监控、按钮操作、系统托盘+快捷键 |
| E2 | MCP Server / JSON CLI | 命令集冻结，每命令输出一行 JSON，与 Python 版一致 |
| E3 | 24×30 常驻（launchd + watchdog） | daemon 心跳持续更新，崩溃自动拉起 |

### F. 系统质量

| # | 需求 | 验收标准 |
|---|---|---|
| F1 | 单一主副本，无混乱 | 全机只有一个生效项目副本（当前：~/Projects/尊者监控直播短视频） |
| F2 | 严格测试 | `cargo test` 全绿、CLI 冒烟通过、实测链路（直播检测/视频列表/下载）通过 |
| F3 | 崩溃可恢复 | 任务队列不永久卡死、录制会话可回收、重试有上限有退避 |
| F4 | 能测的必须测清楚；缺凭据的（邮箱/微信）明确标记跳过原因 | 测试报告逐条记录 |
